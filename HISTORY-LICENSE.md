# Historical license note

Past Cshell releases that shipped the repository `frontend/` tree distributed a Vue UI adapted from [Wei-Shaw/sub2api](https://github.com/Wei-Shaw/sub2api) (baseline commit `2af3f1e15c98c893a89255a037f551046883b8c0`) under **LGPL-3.0-or-later**.

That `frontend/` directory has been removed from the **current** working tree in favor of the independent MIT-intended `web/` UI. **Git history was not rewritten**; historical commits and previously published artifacts that contained `frontend/` still retain that material and the corresponding LGPL obligations for those past distributions.

Current original Cshell materials (including `web/`) are MIT; Sub2API remains a separately deployed backend; third-party dependencies keep their own licenses. See [LICENSE](LICENSE), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), and [docs/provenance.md](docs/provenance.md).
